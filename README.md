# Lab Program Library

A simple personal website to store and open all your lab programs in one place.

## Features
- Add, edit, and delete programs
- Search by title
- Copy code with one click
- Dark and light mode
- Data stored in your browser (Local Storage)
- No database required

## Files
- `index.html`
- `style.css`
- `script.js`

## Run
1. Extract the ZIP.
2. Open `index.html` in Chrome, Edge, or Firefox.

## Share Online
- Upload the folder to GitHub Pages or Netlify.
- For shared data across users, connect a database such as Firebase.
